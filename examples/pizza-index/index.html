1 Introduction

A small ontology about pizzas and their toppings, used to test OntoReview.

2 Competency questions

7 competency questions: 4 answerable, 1 not answerable, 1 query error, 1 not tested. Each query is run against the ontology and its example data when this document is generated.

  1. CQ1 Which pizzas have a meat topping?

    Statusanswerable · 1 result
    Termshas topping, Meat topping
    AnswerThe pepperoni pizza.
    NotesFrom the menu-planning use case.
     
    SELECT ?pizza WHERE { ?pizza pizza:hasTopping ?t . ?t a pizza:MeatTopping . }
    Results
    pizza
    d:pepperoni

  2. CQ2 What kinds of base can a pizza have?

    Statusanswerable · 2 results
    Termshas base
     
    SELECT DISTINCT ?base WHERE { ?p pizza:hasBase ?base . }
    Results
    base
    d:thin
    d:thick
